**Lesson [N] — Search for defect shapes, don't wait for accidents.**

Every defect in this platform's history through Session 115 was found by
someone stumbling into it while doing something else. Session 121 changed
the method: a deliberate, scheduled search against nine already-established
conventions, run across all fifteen workspaces, before any new bug prompted
it. This is a different discipline from Rule 12 — Rule 12 is a same-session
follow-up triggered by having just found something; this was a standalone
audit against a growing list of known defect shapes, accumulated from
unrelated past fixes, run for its own sake.

It found six real, substantive gaps in one pass, with zero code changes —
the session was report-only by design, and every claim was independently
re-verified against its cited file before being written down, correcting
several wrong hits before they ever reached the report. The most
consequential finding: VIGIL, the module whose entire function is being the
human checkpoint on AI-generated work, disclosed nowhere on screen that its
own AI-generated approval and triage briefs were AI-generated — the
platform's central accountability claim, found to have a real hole in the
exact place it mattered most.

**The lesson:** once a defect shape has been independently found and fixed
more than once, in more than one place, by accident, that recurrence is
itself a signal. It is worth a deliberate, scheduled search for the shape's
remaining instances rather than assuming the next occurrence will also turn
up by luck. Two accidental discoveries of the same defect shape is the
threshold worth treating as a trigger for a dedicated survey, not a
coincidence to shrug off.
